# Осмотр

Детектив для телефона: комната, в которой вы стоите, становится местом дела.

Вы отмечаете пол и вещи. После этого сюжет пишется целиком — люди, улики, номера и разговоры. По ходу игры он не дописывается. Когда камера снова узнаёт ту же вещь, улика на ней же.

## Как устроена комната

Телефон в браузере не строит трёхмерную карту. Улика держится за предмет.

- Крупные вещи вроде стола, дивана, кровати, холодильника и телевизора камера может узнать сама.
- Пол, дверь, шкаф, полку и тумбочку вы отмечаете рамкой в центре кадра.
- Для каждой вещи сохраняется маленький кадр. Повторный взгляд сравнивается с ним.
- Если кадр не похож, улика не рисуется в случайном месте.
- Подсказка показывает кадр нужной вещи. Если камера всё равно не ловит, улику можно забрать на доску.

Тело, когда оно есть по завязке, лежит на отмеченном полу и накрыто тканью. В других завязках тела нет, остаются следы.

## Телефон и доска

Номера из четырёх цифр. Звонок — это текстовый разговор с выбором реплик. Доска хранит уже найденное, чтобы не обходить комнату заново.

## Запуск на компьютере

```bash
npm install
```

В `.env` одна строка: `GEMINI_API_KEY=...` (образец в `.env.example`). Ключ остаётся на локальном сервере и в страницу не попадает.

```bash
npm run dev
```

Откроется защищённый адрес, обычно `https://localhost:5175`.

## Телефон в той же сети

Камера на iPhone работает только по https.

1. Компьютер и телефон в одном Wi‑Fi.
2. В терминале будет сетевой адрес, откройте его на телефоне: `https://…:5175`.
3. Подтвердите предупреждение о сертификате.
4. Разрешите камеру.

На опубликованной странице GitHub камера тоже открывается. Если сервер с Gemini недоступен, дело собирается на самом устройстве по тем же правилам: целиком до игры и только по отмеченным вещам.
